One line roasting a smart fridge that refuses to open after midnight, for make.fun's "Midnight Fridge Roast" bounty ($2 in USDC).

> After midnight my fridge runs a door policy: no ID, no snacks, no exceptions, and my ID is in the fridge.

## Run it

```sh
python3 main.py
```

Writes the roast to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
